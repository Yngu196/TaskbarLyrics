# 高 DPI 测试矩阵

> MoeKoeMusic 任务栏歌词插件 — DPI 缩放兼容性测试计划

## 1. 测试维度

| 维度     | 覆盖范围                         |
| ------ | ---------------------------- |
| DPI 缩放 | 100%, 125%, 150%, 175%, 200% |
| 任务栏位置  | 底部、顶部、左侧、右侧                  |
| 显示模式   | 卡拉OK模式、卡片模式                  |
| 多显示器   | 单显示器、双显示器(混合DPI)             |
| 动态切换   | 运行中 DPI 变更                   |

## 2. 单一验证清单

每个测试用例均需验证以下项目：

- [ ] 歌词窗口位置准确嵌入任务栏
- [ ] 文字清晰无 DPI 模糊
- [ ] 窗口尺寸按 DPI 缩放（非硬编码像素）
- [ ] 拖动偏移按 DPI 比例缩放
- [ ] 悬停控制按钮可点击
- [ ] 右键菜单正常弹出
- [ ] 卡拉OK进度条对齐
- [ ] 翻译文本间距合理
- [ ] 跑马灯滚动正常
- [ ] 设置页面正常

## 7. 测试环境配置方法

### DPI 设置

- 设置 → 显示 → 缩放与布局 → 更改文本、应用等项目的大小
- 或右键桌面 → 显示设置

### 任务栏位置

- Win10: 设置 → 个性化 → 任务栏 → 任务栏位置在屏幕上的位置
- Win11: 设置 → 个性化 → 任务栏 → 任务栏行为 → 任务栏对齐方式

### 多显示器

- 需物理双显示器或虚拟显示器

### 截图对比

- 每个用例执行后截图保存
- 与基准图对比偏差 < 5%
